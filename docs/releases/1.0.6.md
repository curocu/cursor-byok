# Cursor BYOK 1.0.6 · Windows x64

适配环境：Cursor 3.27.22 / Windows x64。发布标签：`windows-v1.0.6`。

## 本次变化

不再向 Cursor 的 `RunReady` 消息回传 `routed_model_display_name`，用于隐藏新聊天中的 “Routed to …” 提示及对应评价按钮。实际模型选择、路由、工具调用和流式回复逻辑保持不变。

旧聊天已保存的提示可能继续保留；界面效果需在运行新版后通过新聊天验收。此版本未修改模型列表刷新、同名通道展示或开关状态保留逻辑。

## 包含的适配

继承 1.0.5 的 Cursor 3.27.22 本地推理协议适配、工具 schema 处理、三种 Provider 接口的思考状态回传、模式与子 Agent 配置，以及本地模型的后台记录处理。

## 下载文件

- `Cursor-BYOK-1.0.6-portable.exe`：免安装版。
- `Cursor-BYOK-1.0.6-x64-setup.exe`：NSIS 安装包，可选择安装目录。
- `SHA256SUMS-1.0.6.txt`：以上两个 EXE 的 SHA-256 校验值。

先退出旧 BYOK，再启动新版；重新打开 Cursor 并新建聊天测试。运行包不需要安装 Rust、Node.js 或 CMake。

## 验证

- 发布构建下 14 项相关回归测试全部通过：6 项 Connect 协议、2 项连接生命周期、3 项本地推理、3 项 Provider 契约。
- 前端及构建脚本类型检查通过。
- 前端生产构建、Windows EXE 和 NSIS 打包通过。
- 此前真实 Cursor 的 Agent、文件工具和 Task 子 Agent，以及真实 Chat Completions / Responses 通道已验证。Claude 真实通道、独立 Multitask 完整流程仍待验收。

本次仅发布本机验证的 Windows 产物；GitHub 跨平台 CI 尚未全部通过。没有提供本分支的 macOS / Linux 包，也未配置签名自动更新。

当前 EXE 的应用内更新地址仍指向上游，本分支请从本仓库手动下载升级。本次上传包未进行代码签名。
